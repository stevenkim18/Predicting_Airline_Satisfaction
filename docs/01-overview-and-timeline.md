## 대회 개요

| 항목 | 내용 |
| --- | --- |
| 대회명 | Predicting Airline Satisfaction |
| 시리즈 | Playground Series, Season 6 Episode 10 |
| 주최 | Kaggle (규칙에 명시된 스폰서: Google LLC) |
| 목표 | 항공편 이용객의 만족 여부 `satisfaction`을 예측 |
| 문제 유형 | 이진 분류, 표 형식 데이터 |
| 평가 지표 | ROC AUC. 테스트 행별 `satisfaction=True`의 **확률**을 제출 |
| 수상 | 1~3위 각 Kaggle 상품 선택권. 시리즈에서 상품은 1인당 한 번만 지급되며, 이미 수상한 사람은 다음 팀으로 넘어감 |
| 랭킹 | Kaggle Points 및 Medals 없음 |

이 대회는 초보자가 머신러닝과 특성 공학을 연습하도록 마련된 Tabular Playground Series의 일부다. 시리즈 소개에는 실세계 데이터를 바탕으로 합성한 가벼운 데이터셋을 활용한다고 설명한다. **이 대회 데이터의 구체적 생성 방법은 공개 설명만으로 확인할 수 없으며**, [원본 항공 만족도 데이터셋](https://www.kaggle.com/datasets/arseniyshutko/binary-aviation-satisfaction-129k)에서 영감을 받았고 특성 분포가 비슷하지만 동일하지는 않다고 명시되어 있다. 원본 데이터와 대회 데이터를 같은 행으로 취급하지 않는다. [출처: Overview](https://www.kaggle.com/competitions/playground-series-s6e10/overview), [Data](https://www.kaggle.com/competitions/playground-series-s6e10/data)

공식 인용 표기: Yao Yan, Walter Reade, Elizabeth Park. *Predicting Airline Satisfaction*. Kaggle, 2026. [대회 링크](https://www.kaggle.com/competitions/playground-series-s6e10)
