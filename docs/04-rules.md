## 2. Competition-Specific Rules — 대회별 규칙

| 주제 | 공식 규칙의 핵심 내용 |
| --- | --- |
| 계정 | 참가자 한 명이 Kaggle 계정을 여러 개 만들어 참가·제출할 수 없음 |
| 팀 | 최대 **3명**. 팀 병합은 팀 리더가 수행하며 병합 팀의 누적 제출 횟수 제한을 지켜야 함 |
| 제출 | 하루 최대 **10회**, 최종 심사용 제출은 최대 **2개** 선택 가능 |
| 외부 데이터·모델·도구 | 원칙적으로 허용. 모든 참가자가 동일하게 접근할 수 있어야 하거나 규칙의 비용·접근성에 관한 합리성 기준을 충족해야 함 |
| AutoML | 적절한 라이선스를 확보하고 규칙을 준수한다면 사용 가능 |
| 코드·데이터 공유 | 팀 밖에서 비공개로 공유할 수 없음. 공개 코드는 대회 Discussion 또는 Notebook을 통해 모든 참가자에게 공유해야 함 |
| 테스트 라벨 | 검증·테스트 행을 사람이 수작업으로 라벨링하거나 예측한 정보를 제출에 사용할 수 없음 |
| 최종 순위 | Private Leaderboard 기준. 동점이면 먼저 제출한 항목이 우선 |
| 수상자 의무 | 수상 모델을 재현할 수 있는 학습·추론 코드, 문서, 실행 환경 설명을 제공해야 할 수 있음 |

공식 규칙에는 자격 요건, 오픈소스 라이선스, 개인정보, 세금, 준거법 등도 포함된다. 특히 외부 도구나 데이터 사용, 공개 코드 배포, 수상 자격을 판단할 때는 해당 조항의 원문을 확인한다. [출처: Rules](https://www.kaggle.com/competitions/playground-series-s6e10/rules)

## 데이터와 코드 사용

- 대회 규칙은 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 조건과 함께 대회 데이터의 상업적·비상업적 이용을 허용한다. 동시에 미참가자에게 데이터를 제공하거나 재배포하는 행위를 제한하는 데이터 보안 조항을 둔다. 외부 공개를 계획할 때 두 조항을 함께 확인한다.
- 외부 데이터와 모델은 주최 측이 별도로 금지하지 않았다면 사용할 수 있다. 자료가 모든 참가자에게 동등하게 접근 가능하고 무료이거나, 규칙의 비용·접근성에 관한 합리성 기준을 충족해야 한다.
- AutoML 도구는 적절한 사용 라이선스를 확보하고 다른 대회 규칙을 지키는 경우 사용할 수 있다.
- 대회 기간에 팀 밖으로 관련 코드를 비공개 공유할 수 없다. 공개 코드는 해당 대회 Discussion 또는 Notebook에 게시해 모든 참가자가 볼 수 있게 해야 한다. 오픈소스 코드 사용에도 공식 규칙의 라이선스 조건이 적용된다.
